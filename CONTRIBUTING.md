Thanks for your interest in contributing to Artemis' Laboratory Blocks.

Contributions that improve the mod, fix bugs, improve compatibility, add suitable building content, or improve documentation are welcome.

## Before You Start

- Check existing issues before reporting or implementing the same problem or idea.
- For larger features or significant changes, open a feature request first so the idea can be discussed before substantial work is done.
- Keep contributions focused. Unrelated changes should be submitted separately.
- Work against the branch matching the Minecraft version and mod loader your change targets.

## Branches and Version Support

Laboratory Blocks uses separate branches for different Minecraft versions and loaders.

When opening a pull request, select the branch matching the version you actually developed and tested against.

Do not target the `assets` branch for code changes.

A contribution accepted for one version does not necessarily mean it will be ported to every older or newer version.
