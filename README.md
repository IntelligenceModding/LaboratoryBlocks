Description
=======

Build clean, modern, and futuristic laboratory spaces with Artemis' Laboratory Blocks, a NeoForge mod for Minecraft 1.21.11.

This mod adds connected laboratory walls, reinforced structure blocks, vents, fans, indicator blocks, laboratory screens, themed floors and tiles, doors, trapdoors, and supporting building details for technical interiors and sci-fi builds, with connected texture support through Fusion.
Perfect for players who want sterile research facilities, industrial corridors, control rooms, and high-tech worldbuilding materials that still fit naturally into Minecraft construction.

Installation information
=======

Built for Minecraft 1.21.11 using NeoForge.

Fusion is a mandatory dependency for this mod.
Laboratory Blocks does not work properly without Fusion installed.
