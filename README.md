Description
=======

Build clean, modern, and futuristic laboratory spaces with Artemis' Laboratory Blocks.

This mod adds connected laboratory Blocks, reinforced structure blocks, vents, fans, indicator blocks, laboratory screens, themed floors and tiles, doors, trapdoors, with connected texture support through Fusion.
Perfect for players who want sterile research facilities, industrial corridors, control rooms, and high-tech world building materials that still fit naturally into Minecraft construction.

Installation information
=======

Built for Minecraft using NeoForge.

Fusion is a mandatory dependency for this mod.
Laboratory Blocks does not work properly without Fusion installed.
